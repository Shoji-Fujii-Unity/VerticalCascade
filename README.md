# VERTICAL CASCADE

VERTICAL CASCADE is a vertical match-3 puzzle for smartphones and PC.  
This game runs in a web browser and can be opened from a single HTML file.

## Languages

This README is provided in all languages supported by the game:

- English
- 日本語
- 中文
- Français
- Español
- 한국어

The game supports language switching from the header menu.

## English

### Overview

VERTICAL CASCADE is a vertical match-3 game.  
Swap adjacent gems to line up three or more matching gems.  
Cleared gems disappear, and gems above fall downward.  
Longer cascades give higher scores.

### Run the Game

1. Save the game HTML file as index.html.
2. Open index.html in a modern browser.
3. Use the game directly in the browser.

Recommended browsers:

- Chrome
- Edge
- Safari
- Firefox

The game also works on mobile browsers such as Chrome on Android and Safari on iPhone.

### Controls

Mobile:

- Tap a gem to select it.
- Tap an adjacent gem to swap.
- Swipe a gem to swap in the swipe direction.

PC:

- Click a gem to select it.
- Click an adjacent gem to swap.

### Game Rules

- The board is 6 columns wide and 10 rows tall.
- Gems are distinguished by color and symbol.
- Swapping adjacent gems forms a match when three or more gems of the same type line up horizontally or vertically.
- Matched gems disappear.
- Gems above move downward.
- New gems appear from the top.
- Cascading matches give bonus points.
- The level target increases as you advance.

### Sound

Sound On and Sound Off controls are available from the top control area.

- On: sound effects are enabled.
- Off: all sound effects are muted.

The sound setting is saved locally in the browser.

### Privacy

- No account is required.
- No personal data is collected.
- Settings such as language and sound are saved only in the local browser storage.
- The game can run offline after the file is opened.

### File Structure

This game is intended to run from a single file:

- index.html

This README may be placed in the same folder for documentation.
